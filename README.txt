GAURI WARAD - AWS S3 PORTFOLIO

FILES:
1. index.html       Main portfolio page
2. style.css        Website styling
3. script.js        Small JavaScript enhancement
4. resume.pdf       Your resume (copy your uploaded PDF into this folder with this exact name)

AWS S3 HOSTING:
1. Create an S3 bucket with a globally unique name.
2. Upload index.html, style.css, script.js and resume.pdf.
3. In Properties -> Static website hosting, enable hosting and set index document to index.html.
4. For a simple public portfolio, configure the bucket/object access according to your AWS lab instructions. Do not make your personal files public unless you intend to.
5. Open the S3 website endpoint shown by AWS.

IMPORTANT:
The resume button expects a file named resume.pdf in the same S3 folder as index.html.
